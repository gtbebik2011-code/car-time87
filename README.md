# Car Time 87

Перший етап сайту за наданим макетом: шапка, три фото херо, чотири картки послуг. Окремий проєкт без зовнішніх залежностей.

## Локальний запуск

`npm run dev` — http://127.0.0.1:3087

`npm run check` — перевірка синтаксису JavaScript.

Сайт у `dist/` готовий для статичного хостингу. Фото та шрифти зберігаються локально. Головний файл — `dist/index.html`, стилі — `dist/styles.css`, інтерактивність — `dist/app.js`.

Заголовки, кольори, відступи та композиція відтворені зі зразка. Логотип — тимчасове SVG-відтворення за макетом; шрифт — Manrope, найближчий доступний локальний варіант. Замінити на оригінали, коли будуть надані. Номер 099 468 8456 перенесено з макета; перевірити перед відкриттям сайту для клієнтів.

Кнопки послуг відкривають опис; запис відкриває контактне вікно з телефонним посиланням. Форма заявок і бекенд не додавалися. Посилання на розділи наступного етапу відкривають повідомлення «незабаром».
