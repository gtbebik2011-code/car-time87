# Car Time 87

Перший етап сайту за наданим макетом: шапка, три фото херо, чотири картки послуг. Окремий проєкт без зовнішніх залежностей.

## Локальний запуск

`npm run dev` — http://127.0.0.1:3087

`npm run check` — перевірка синтаксису JavaScript.

Сайт у `dist/` готовий для статичного хостингу. Фото та шрифти зберігаються локально. Головний файл — `dist/index.html`, стилі — `dist/styles.css`, інтерактивність — `dist/app.js`.

Заголовки, кольори, відступи та композиція відтворені зі зразка. Логотип — тимчасове SVG-відтворення за макетом; шрифт — Manrope, найближчий доступний локальний варіант. Замінити на оригінали, коли будуть надані. Номер 099 468 8456 перенесено з макета; перевірити перед відкриттям сайту для клієнтів.

Кнопки послуг відкривають опис; запис відкриває контактне вікно з телефонним посиланням. Форма заявок і бекенд не додавалися. Посилання на розділи наступного етапу відкривають повідомлення «незабаром».

## Другий етап — локальна версія
Додано секцію результатів із повзунком порівняння: work-before.png — перше фото користувача, work-after.png — друге. Додаткові приклади використовують фото автомобілів, надані раніше. Працюють гортання, розгортання всіх робіт та перегляд фото у модальному вікні. Картки послуг затемнені до 68% і плавно світлішають до 91% при наведенні або потраплянні у видиму область на телефоні. Подальша робота ведеться локально за побажанням користувача; цей етап не публікувався.

## Третій етап
Додано переваги студії, секцію «Увага до деталей», надане фото студії, розгортання опису та перегляд фото. Показники 3+ і 500+ взяті з початкового макета. Заголовок херо отримав більший міжлітерний інтервал. Зміни залишаються локальними.

## Четвертий етап — рекомендації для клієнтів
Додано три картки з наданими фото, категоріями та текстами статей. Статті відкриваються у вікні з ілюстрацією; «Всі статті» відкриває список. На телефоні працює горизонтальне гортання і кнопки навігації. «Корисне» веде до секції #tips. Перевірено відкриття статті, список, мобільне гортання, завантаження фото та відсутність горизонтального переповнення. Цей етап залишено локально.

## П’ятий етап — відгуки та футер
Додано карусель відгуків із текстами й іменами з початкового макета та ініціалами замість ненаданих портретів. Темний футер містить навігацію, логотип, телефон із макета та перехід угору. Форма відгуків зберігає дані лише в localStorage цього браузера й прямо пояснює це користувачу; серверного збору й публікації немає. Перевірено вигляд на комп’ютері й телефоні, гортання, обов’язкові поля форми, цілі навігації та відсутність переповнення екрана. Публікацію не виконували.

## Публікація на GitHub Pages
Підготовлено .github/workflows/pages.yml: після push у main workflow перевіряє JavaScript і публікує папку dist через GitHub Pages. У репозиторії джерело Pages потрібно встановити на GitHub Actions. Усі локальні посилання на фото, шрифти, стилі й скрипти відносні та підтримують адресу проєкту /car-time87/. Сервер server.mjs для GitHub Pages не потрібний.
Інструкція GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages
